# aws-playground

Having fun while learning AWS.

A personal playground to experiment, build, break things and learn how AWS works in practice.

## What you'll find here

- **Infrastructure** — Building and managing cloud infrastructure.
- **Security** — Exploring IAM, permissions and AWS security services.
- **Automation** — Infrastructure as Code, Terraform and scripting.
- **Development** — Serverless applications, APIs and cloud integrations.
- **Architecture** — Designing scalable, resilient and cost-effective solutions.
- **Labs & Experiments** — Hands-on exercises, tests and random AWS experiments.

## Goals

- Learn AWS by building real-world projects.
- Prepare for the AWS Solutions Architect Associate certification.
- Experiment with different AWS services and architectures.
- Document what I learn along the way.

## Disclaimer

This repository is intended for learning and experimentation. Projects may be incomplete, experimental or subject to change.
